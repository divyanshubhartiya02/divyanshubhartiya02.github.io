# Divyanshu Bhartiya - Data Science & AI Portfolio

Personal portfolio site, live at https://divyanshubhartiya02.github.io

Built with Jekyll (remote theme: analytics-link) and hosted on GitHub Pages.

## Structure
- `_config.yml` - site title, bio, links, resume path
- `_posts/` - one markdown file per project
- `img/posts/` - project images
- `img/profile_picture.JPG` - profile photo
- `docs/Divyanshu_Bhartiya_Resume.pdf` - resume (linked from the homepage)
